# Level III-RT — 아직 낼 수 없는 문항

원본이 서술형이다. 답이 여러 조각이라 주관식으로 내면 아는 사람도
글자를 그대로 못 쳐서 틀린다. 두 갈래 가운데 하나를 골라야 한다.

  가) 오답 보기 셋을 채워 객관식으로 낸다
  나) 답을 한 조각으로 줄여 주관식으로 낸다  (보기 없이 답만 두면 된다)

해당 종목 NDE Level Ⅲ 가 정해 승인한다. (HIE-QP-E02 6.1.2, 6.3.1)

---

### id 1

```
What requirement of this procedure shall be demonstrated on production or technique radiograph for its qualification?
방사선 투과사진 기술 또는 제작에 대한 품질을 입증하기 위하여 이 절차서에서의 요구사항은 무엇인가?
```

원본 정답 : `Density and penetrameter image requirements / 농도와 투과도계 상(image) 요구사항`

### id 2

```
For complete radiographic coverage of cylindrical girth welds, a minimum of is required when the source is placed outside and the film inside the object.
원주 용접부의 양호한 방사선 투과사진 적용범위에 대하여 선원이 외부 그리고 내부에 위치했을 때 최소 어느 정도 요구되는가.
```

원본 정답 : `Four exposures 90° apart / 90° 간격 4회 촬영`

### id 4

```
What is the different requirements in this procedure between X-ray and γ-ray?
절차서에서 X선과 감마선 사이의 다른 요구조건은 무엇인가?
```

원본 정답 : `Minimum film density 1.8 for X-ray / 2.0 for Gamma-ray / 최소 필름농도 X선 1.8 / 감마선 2.0`

### id 5

```
What evidence would you find on a radiograph that would indicate insufficient protection from back-scatter?
투과사진 상에서 후방산란을 대비한 불충분한 방어를 나타내는 어떤 증거를 발견할 수 있나?
```

원본 정답 : `B letter appears on a dark background of the radiograph / 방사선사진의 어두운 바탕 위에 B 글자가 나타난다`

### id 6

```
What are the radiographic density requirements?
투과사진에서 요구되어지는 농도는?
```

원본 정답 : `Single viewing for X-ray : 1.8~4.0 / Composite viewing of multiple film : 1.3~4.0 / Single viewing for γ-ray : 2.0~4.0 / X선 단일필름 관찰 1.8~4.0 / 다중필름 겹쳐 관찰 1.3~4.0 / 감마선 단일필름 관찰 2.0~4.0`

### id 10

```
A circumferential butt weld in class 1 component has been made in a 30 in. diameter pipe. The inside of the pipe is not accessible. The wall thickness is 5/8" and the reinforcement is the maximum allowed by the procedure. What is the maximum reinforcement allowed? What is the required minimum wire IQI diameter?
1등급 기기인 외경 30인치 원주 용접부가 있다. 파이프 내부는 접근불가하며 벽두께는 5/8인치이고 용접덧살은 절차서 허용 최대 크기이다. 최대 허용 용접덧살과 요구되는 최소 선형 투과도계 직경은?
```

원본 정답 : `A : 3/32 inch / B : #7 wire (0.013 inch or 0.33mm) / A: 3/32인치 / B: #7 와이어(0.013인치, 0.33mm)`
