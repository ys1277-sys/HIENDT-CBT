# Level III-MT — 아직 낼 수 없는 문항

원본이 서술형이다. 답이 여러 조각이라 주관식으로 내면 아는 사람도
글자를 그대로 못 쳐서 틀린다. 두 갈래 가운데 하나를 골라야 한다.

  가) 오답 보기 셋을 채워 객관식으로 낸다
  나) 답을 한 조각으로 줄여 주관식으로 낸다  (보기 없이 답만 두면 된다)

해당 종목 NDE Level Ⅲ 가 정해 승인한다. (HIE-QP-E02 6.1.2, 6.3.1)

---

### id 2

```
How much time is needed to adapt to dark viewing prior to performing fluorescent examination?
형광 시험을 수행하기 전에 어두움에 적응하기 위해 필요한 시간은?
```

원본 정답 : `At least 5 minutes / 최소 5분`

### id 5

```
How much is a limited range of the temperature when using the wet particle suspension?
습식 자분 현탁액 사용 시 온도 제한 범위는?
```

원본 정답 : `Not exceed 135°F (57℃) / 135°F(57℃)를 넘지 않을 것`

### id 7

```
When using the yoke, how much spacing of Yoke-pole?
요크를 사용할 때 극간 간격은 얼마인가?
```

원본 정답 : `Minimum 50 to Maximum 130 mm / 최소 50mm에서 최대 130mm`
