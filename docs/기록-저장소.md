# 기록 저장소

시험 결과가 한 곳에 차곡차곡 쌓이는 자리다.
**스프레드시트 하나가 저장소이고, 시트 하나가 서식 하나다.**

구조는 규칙이 정한 그대로다.

- **HIE-QP-E02 7.10.3** — 이 규칙에 따라 남기는 기록
- **HIE-QP-E03 9.0** — 자격증 발행 및 관리 규칙의 양식
- **HIE-QP-E02 7.10.1** — 퇴사 후 5년 보존. 이 저장소는 아무것도 지우지 않는다
- **HIE-QP-E02 7.10.4** — 폐기는 대표 NDE Level Ⅲ 승인을 받아 사람이 한다

---

## 1. 시트 한 벌

| 시트 | 서식 | 무엇이 쌓이나 | 누가 채우나 |
|---|---|---|---|
| `응시기록` | — | 시험 한 건마다 한 줄 | **CBT 자동** |
| `E02-07 채점결과` | 채점결과보고서 | 회차마다 한 줄 (인원·합격자·합격률) | **CBT 자동** |
| `E03-01 발급대장` | 자격증 발급대장 | 발급 대상 후보 | CBT + 사람 |
| `E03-04 만료예정` | 자격 만료 예정자 명단 | 기준일자마다 한 벌 | CBT + 사람 |
| `요원` | — | 요원 명부 (시험으로 안 나오는 값) | 사람 |
| `E02-01 시행계획` | 시행계획서 및 응시자 명단 | 회차마다 | 사람 |
| `E02-02 감독` | 감독 관리사항 | 회차마다 | 사람 |
| `E02-04 폐기대장` | 시험문제 폐기 대장 | 종이 시행분 폐기할 때 | 사람 |
| `E02-05 부정행위` | 부정행위 처리 기록 | 적발했을 때 | 사람 |
| `E02-06 은행접근` | 문제은행 접근 기록 | 접근할 때마다 | 사람 |
| `E03-03 재발급` | 자격증 재발급 대장 | 재발급할 때 | 사람 |
| `E03-05 자격종료` | 자격종료·복권 기록 | 자격이 끝났을 때 | 사람 |

**E02-03 응시자 유의사항 서명본**은 종이에 손으로 서명받는 것이라 시트로
관리하지 않는다. 스캔하여 회차별로 보관한다.

**E03-02 재발급 신청서**는 본인이 써서 내는 종이라 시트가 없다.
접수하면 `E03-03 재발급` 에 한 줄 적는다.

## 2. 무엇이 저절로 쌓이나

### 응시 결과를 제출하면

```
응시자 제출
   │
   ├─→  응시기록          한 줄 붙는다
   │
   └─→  E02-07 채점결과   그 회차를 다시 세어 갱신한다
```

**회차는 「시행일 + 등급 + 종목 + 구분」이다.** 같은 날 같은 시험을 친
사람은 한 줄로 묶인다. 사람이 한 명씩 제출하므로 인원과 합격률이 계속
바뀌는데, 제출할 때마다 응시기록에서 처음부터 다시 세므로 늘 맞는다.

| 시행일자 | 등급 | 시험 | 종목 | 출제문항 | 응시인원 | 합격자 | 합격률 | 응시자 |
|---|---|---|---|---|---|---|---|---|
| 2026-05-20 | Level II | 일반시험 | UT | 40 | 2 | 1 | 50 | 김철수, 홍길동 |
| 2026-06-11 | Level II | 전문시험 | PT | 20 | 1 | 1 | 100 | 박민수 |

회차번호·채점장소·확인자·승인자는 사람이 채운다.

### 발급대장과 만료 예정자는 단추로

이 둘은 응시 결과에서 바로 나오지 않는다 — 종합점수 판정, 만료일 계산,
요원 명부가 함께 있어야 한다. 그 계산은 앱이 하고 저장소는 받은 줄을
얹기만 한다. **같은 계산을 두 곳에 두면 언젠가 어긋난다.**

`관리자` → `자격 이력` → **「기록 저장소에 올리기」**

만료 예정자는 **기준일자마다 한 벌**이 쌓인다. 화면은 열 때마다 다시
계산하지만 「2026년 8월에 누가 만료 예정이었나」는 그때 올려 둬야 남는다.

### 사람이 적은 칸은 지킨다

발급일자·수령확인·통보일자·처리 같은 칸은 저장소가 **절대 건드리지
않는다.** 다시 올려도 그 줄의 CBT 몫 칸만 고친다.

```
1) CBT 가 올림     홍길동 | Level II | UT | 인증 2026-05-25 | 만료 2029-05-31
2) 사람이 적음                                    발급일자 2026-06-01, 수령 홍길동
3) CBT 가 다시 올림                               발급일자 2026-06-01, 수령 홍길동  ← 그대로
```

## 3. 붙이는 법

### 3.0 예전 기록 옮기기

예전 스크립트가 쓰던 시트(보통 `시트1`)에 여태 결과가 쌓여 있다.
**머리행이 없고 칸 차례가 곧 뜻이었다.**

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| 응시일시 | 성명 | 등급 | 종목 | 구분 | 점수 | 결과 | 문항 | 답 |

시트 이름만 `응시기록` 으로 바꿔서는 안 된다.

- `응시기록` 은 이미 만들어져 있어 **같은 이름을 쓸 수 없다**
- 머리행이 없어 칸이 밀린다
- 응시일시가 `2026. 7. 23. 오후 1:01:56` 꼴이라 날짜로 안 읽힌다.
  그대로 두면 회차가 `2026. 7. 2` 로 잘려 다른 날 시험이 한 회차로 엉킨다

배포 주소에 **`?do=migrate`** 를 붙여 열면 스크립트가 옮긴다.

```
https://script.google.com/macros/s/…/exec?do=migrate
```

```json
{"ok":true,"from":"시트1","moved":178,"skipped":0,"sessions":23,
 "message":"시트1 의 178줄을 응시기록으로 옮기고 회차 23개를 집계했습니다. 원본은 그대로 두었습니다."}
```

하는 일

1. 칸 차례대로 읽어 이름 붙은 칸에 넣는다
2. `2026. 7. 23. 오후 1:01:56` 을 `2026-07-23T13:01:56+09:00` 으로 푼다
3. 등급·구분에서 갈래(일반·전문·기초·종목)를 매긴다
4. 회차를 묶어 `E02-07 채점결과` 를 채운다

**원본 시트는 지우지 않는다.** 기록은 임의로 폐기하지 않는다 (E02 7.10.4).
옮긴 것을 확인한 뒤 사람이 판단해 지운다.

> 시트 이름이 `시트1` 이 아니면 `?do=migrate&from=시트이름` 으로 알려 준다.
>
> `응시기록` 에 이미 줄이 있으면 **멈춘다.** 두 번 옮겨 기록이 겹치는 것을
> 막기 위한 것이다. 정말 다시 옮기려면 `응시기록` 의 머리행만 남기고 비운다.

### 3.1 Apps Script 넣기

스프레드시트 → **확장 프로그램 → Apps Script** → `Code.gs` 를
[`docs/Code.gs`](Code.gs) 내용으로 통째로 바꾼다.

### 3.2 시트 만들기 — 할 일 없음

시트는 **저절로 만들어진다.** 첫 요청이 들어올 때 한 번 훑어 없는 시트를
만들고 빠진 머리행을 붙인다. 다음 요청부터는 훑지 않는다.

> 편집기의 함수 목록에서 `setup` 을 눌러 미리 만들어 두어도 된다.
> 다만 **붙여넣고 저장(Ctrl+S)하기 전에는 목록이 갱신되지 않아 `setup` 이
> 안 보인다.** 안 보여도 상관없다 — 배포하고 나면 저절로 만들어진다.

시트를 실수로 지웠거나 머리행을 바꿨으면 배포 주소에 **`?do=setup`** 을
붙여 열면 다시 훑는다.

```
https://script.google.com/macros/s/…/exec?do=setup
```

여러 번 돌려도 된다. 이미 있는 시트는 그대로 두고 빠진 칸만 뒤에 붙인다.
**이미 있는 칸을 옮기거나 지우지 않는다.**

### 3.3 배포

**배포 → 배포 관리 → 기존 배포 편집(연필) → 버전 「새 버전」 → 배포**

배포 설정은 이렇게 되어 있어야 한다.

| 항목 | 값 | 왜 |
|---|---|---|
| 실행 대상 | **나** | 시트를 열 권한이 필요하다 |
| 액세스 권한 | **모든 사용자** | 시험 단말은 구글 로그인 없이 결과를 보낸다 |

> 「새 배포」를 만들면 주소가 바뀌어 앱이 저장소를 못 찾는다.
> 주소를 바꿔야 한다면 `src/Admin.jsx` 와 `src/Result.jsx` 의
> `SHEET_URL` 도 같이 고친다.

### 3.4 요원 명부 채우기

`요원` 시트에 사람마다 한 줄 적는다. **`name` 은 응시할 때 적는 이름과
똑같아야 한다** — 이것으로 응시 기록과 이어 붙인다.

| 칸 | 뜻 | 예 | 규정 |
|---|---|---|---|
| name | 성명 | 홍길동 | E03 8.2.1 1) |
| dept | 소속 | 검사1팀 | |
| empNo | 사번 | 2021-014 | |
| eyeExamDate | 시력검사일 | 2026-06-01 | E01 7.3.2 |
| certifiedAt | 자격인정 일자 | 2026-03-10 | E03 8.2.1 9) |
| hiredAt | 업무종사 일자 | 2021-03-02 | |
| terminatedAt | 퇴사일 (보존기간 계산) | | E01 7.6.6 |
| education | 학력 | 기계공학 전문학사 | E03 8.2.1 3) |
| experience | 경력 | UT 1,200시간 | |
| training | 교육훈련 이수 | UT Level Ⅱ 80시간 (2026-02) | E03 8.2.1 4) |
| approvedBy | 자격인증 확인 Level Ⅲ | 김OO | E03 8.2.1 8) |
| employerSign | 고용주 서명 확인 | 2026-03-12 | E03 8.2.1 11) |

**날짜는 `YYYY-MM-DD` 로 적는다.**

종목마다 인증일이 다르면 **`certifiedAt:종목`** 칸을 더 만든다.

| name | certifiedAt | certifiedAt:RT | certifiedAt:UT |
|---|---|---|---|
| 홍길동 | 2026-03-10 | 2024-05-08 | 2026-03-10 |

종목 칸이 있으면 그것을, 없으면 `certifiedAt` 을 쓴다.

### 바깥 기관 자격 — 필기시험 면제

유효한 ASNT NDE Level Ⅲ 나 ISO 9712 자격을 가진 사람은 일부 필기시험을
치르지 않는다 (E01 7.3.5 · 7.3.7 · HIE-QP-E02 5.1.5).

| 칸 | 뜻 | 예 |
|---|---|---|
| exempt | 자격 이름 | `ASNT III` · `ISO9712 III` · `ISO9712 II` |
| exemptNo | 자격번호 | ASNT-123456 |
| exemptExpiry | 자격 만료일 | 2029-06-30 |

| 가진 자격 | 안 치르는 시험 | 치르는 시험 |
|---|---|---|
| ASNT III · ISO9712 III | 기초, 종목 | **전문** |
| ISO9712 II | 일반 | **전문** |

**치르는 시험의 합격선은 80%다.** 개별 70% 가 아니다. 이력 화면이
이것을 알아서 갈라 본다.

종목마다 다르면 **`exempt:종목`** 또는 **`exempt:등급/종목`** 칸을
더 만든다. 등급+종목 칸이 가장 먼저다.

| name | exempt | exempt:UT | exempt:Level III/MT |
|---|---|---|---|
| 홍길동 | ISO9712 II | ASNT III | ISO9712 III |

자격번호와 만료일은 응시자 명단(HIE-QP-E02-01)에도 적는다.
**적어 두기만 하면 면제되는 것이 아니다** — NDE Level Ⅲ / QA 가 자격증
원본으로 확인해야 한다 (E02 5.1.5).

### 3.5 붙었는지 확인

1. 배포 주소 뒤에 **`?sheet=sheets`** 를 붙여 연다 — 시트 열둘과 줄 수가 나온다.
2. **`?sheet=people`** — 요원 명부가 나오면 붙은 것이다.
3. CBT `관리자` → `자격 이력` 에서 주황색 안내(「요원 명부가 없어…」)가
   사라져 있으면 된 것이다.

## 4. 주고받는 것

| | 무엇 |
|---|---|
| `POST {type:"exam", …}` | 응시 결과 한 건. 응시기록 + E02-07 갱신 |
| `POST {type:"sync", certLog, expiry}` | E03-01 · E03-04 갱신 |
| `GET` | 응시기록 |
| `GET ?sheet=people` | 요원 명부 |
| `GET ?sheet=sheets` | 시트 목록과 줄 수 |
| `GET ?do=setup` | 시트와 머리행을 다시 훑는다 |
| `GET ?do=migrate` | 예전 시트의 줄을 응시기록으로 옮긴다 |
| `GET ?sheet=E02-07 채점결과` | 그 시트를 통째로 |

## 5. 고치기 전에 돌려 볼 것

Apps Script 는 구글 서버에서만 도는 것이라 붙여 보기 전에는 확인할
방법이 없다. 시트를 흉내 낸 껍데기 위에서 돌려 보는 검사를 두었다.

```bash
node tools/store-test.mjs
```

`setup` 이 시트 열둘을 만드는지, 같은 회차가 한 줄로 묶이는지, 사람이
적은 칸을 지키는지를 값으로 확인한다. **`docs/Code.gs` 를 고치면 붙여넣기
전에 이것부터 돌린다.**

## 6. 아직 손으로 하는 것

저장소에 시트는 있지만 **CBT 가 채우지 않는 기록**이다. 화면에서 빈 서식을
뽑아 쓰고(`자격 이력` → `서식` 탭), 적은 내용을 시트에 옮긴다.

| 기록 | 서식 | 언제 |
|---|---|---|
| 시행계획서 및 응시자 명단 | E02-01 | 시험일 7일 전까지 |
| 감독 관리사항 | E02-02 | 시험 전날 ~ 종료 후 |
| 시험문제 폐기 대장 | E02-04 | 종이 시행분을 폐기할 때 |
| 부정행위 처리 기록 | E02-05 | 적발했을 때 |
| 문제은행 접근 기록 | E02-06 | 접근할 때마다 |
| 자격증 재발급 대장 | E03-03 | 재발급할 때 |
| 자격종료·복권 기록 | E03-05 | 자격이 끝났을 때 |
