01 채점 실수

사람이 정답지를 보고 매기면 틀릴 수 있습니다. 자격이 걸린 시험에서는 되돌리기 어렵습니다. 이제 같은 시험은 언제 채점해도 같은 점수가 나옵니다.

02 시험지 유출

복사한 시험지가 돌아다닐 일이 없습니다. 종이로 시행할 때만 출력하고, 폐기 대장(HIE-QP-E02-04)도 함께 뽑습니다.

03 만료 놓침

자격이 언제 끝나는지, 시력검사를 언제 다시 받아야 하는지 사람이 기억하지 않아도 됩니다. 만료 3개월 전에 명단이 나옵니다.

문제 유형은 세 가지입니다

유형마다 답하는 법이 다릅니다. 화면이 무엇을 하라고 알려 줍니다.

① 사지선다

가장 많습니다. 넷 중 하나를 누릅니다.

보기가 두세 개뿐이던 86문항도 모두 넷으로 맞췄습니다. 찍어서 맞힐 확률이 종목마다 달라지면 안 되기 때문입니다.

② 복수 정답

화면에 “정답이 여러 개인 문항입니다. 해당하는 것을 모두 고르세요.” 라고 뜹니다. 해당하는 것을 모두 눌러야 맞습니다.

하나라도 빠지거나 더 고르면 틀립니다.

DEGRAD ← 지우기

  1. 시험 화면 오른쪽 위 「🖩 계산기」로 열고 닫습니다. 따로 챙겨 올 필요가 없고, 시험 중에 화면을 벗어나지 않습니다.
  2. 도(°) 모드가 기본입니다. NDT 계산은 각도를 도로 씁니다. 굴절각·스넬의 법칙을 그대로 넣으면 됩니다.
  3. 시험 중에 절차서를 펴 볼 수 있습니다. 「절차서 안에서 찾기」로 낱말을 넣으면 그 자리로 갑니다. 전문시험은 절차서에서 나옵니다.

고침 조용히 틀리던 것

  • sin(30) 이 0.5가 아니라 −0.988 — 라디안 기준이었습니다
  • log 가 자연로그였습니다 — dB 계산이 전부 틀렸습니다
  • ln 은 누르면 무조건 오류였습니다

셋 다 바로잡았습니다.

종이를 버린 게 아닙니다. 단말이 모자라거나 정전일 때, 감사 자료가 필요할 때 언제든 뽑습니다.

① 시험지 출력

첫 화면의 「문제은행 출력」. 갑지에 회사 로고와 응시자 기입란이 들어갑니다. 그대로 종이 시험으로 씁니다.

② 답안지 출력

결과 화면의 「문제지 출력」. 푼 답과 채점 결과를 그대로 찍습니다. 본인 확인과 보관용입니다.

③ 관리자용 출력

관리자 화면의 「결과지 출력」. 정답과 근거를 함께 찍습니다. 감독자·평가자가 씁니다.

세 가지 모두 전 장 가운데에 회사 로고 워터마크가 옅게 들어갑니다 — 글씨를 가리지 않는 농도로 맞췄습니다. 여기에 더해 규정 서식 9종(시행계획서 · 감독 관리사항 · 응시자 유의사항 · 문제 폐기 대장 · 부정행위 기록 · 문제은행 접근 기록 · 자격증 재발급 신청서 · 재발급 대장 · 자격종료 복권 기록)을 빈 양식으로 뽑을 수 있습니다.

문항 파일은 사람이 읽을 수 있는 글입니다. 프로그램을 몰라도 문제와 보기, 정답 번호를 알아볼 수 있습니다. 고친 자리마다 왜 고쳤는지 적는 칸이 따로 있습니다.

Ⅳ-0302 올린다

검사하고, 올리면 끝

# 1. 고친 것이 성립하는지 먼저 본다
node tools/verify.mjs
전체 통과

# 2. 무엇을 왜 고쳤는지 적어 남긴다
git add -A
git commit -m "MT 일반 9번 정답 바로잡음"

# 3. 올린다 — 이 한 줄이면 배포까지 간다
git push

검사에서 하나라도 걸리면 올리기 전에 드러납니다. 잘못된 문항이 응시자 화면까지 가지 않습니다.

  1. push 하면 GitHub 이 스스로 돕니다. 내려받기 → 빌드 → 웹에 올리기까지 사람이 손대지 않습니다 (.github/workflows/deploy.yml).
  2. 2~3분이면 반영됩니다. 배포할 때마다 문항 파일을 새로 받게 해 두어, 브라우저가 예전 문제를 들고 있는 일이 없습니다.
  3. 되돌릴 수 있습니다. 고친 기록이 전부 남아 있어, 잘못되면 예전 상태로 되돌려 다시 올리면 됩니다.

01 설치가 없습니다

브라우저만 있으면 됩니다. 회사 PC, 노트북, 태블릿 — 어디서든 같은 화면입니다.

02 사내망이 아니어도 됩니다

현장이나 출장지에서도 칠 수 있습니다. 시험장을 따로 잡지 않아도 됩니다.

03 늘 최신입니다

문항을 고쳐 올리면 다음에 여는 사람부터 바로 그 문항을 봅니다. 배포본을 나눠 줄 일이 없습니다.

Ⅳ-0605 확인한다

첫 화면 오른쪽 아래 「관리자」 → 비밀번호를 넣으면 들어갑니다.

  • 인증일자 · 만료일자 · 상태
  • 빠진 시험은 「미응시」로 표시

관리자 화면은 비밀번호로 막혀 있습니다. 다만 지금 방식은 임시입니다 — 비밀번호가 화면 쪽에 들어 있어, 제대로 하려면 확인하는 자리를 구글 쪽으로 옮겨야 합니다. 남은 일에 적어 두었습니다.

Ⅳ-04옮기다 찾은 것

규정보다 적게 나가던 시험

종이를 프로그램으로 옮기려면 규정을 한 줄씩 다시 읽어야 했습니다. 그러다 드러난 것들입니다.

있던 일
  1. 전 종목을 일반 40 · 전문 25로 못 박아 두었습니다. E01 표 3은 종목마다 다릅니다.
  2. 그래서 TOFD·PAUT 전문시험이 규정보다 5문항 적게 나갔습니다.
  3. Level Ⅲ 종목시험은 은행 전체가 나가 104문항이 되기도 했습니다. 시험시간은 2시간 — 문항당 69초였습니다.
  4. 문제은행이 규정 출제 수와 같아 회차마다 같은 문제가 나갔습니다.
지금
  1. 출제 수를 E01 표 3 그대로 종목마다 따로 정했습니다.
  2. TOFD·PAUT 전문 30문항, Level Ⅲ 기초 55 종목 65.
  3. 은행에는 규정 수보다 넉넉히 넣고, 시작할 때 그중에서 무작위로 뽑습니다.
  4. 보기 순서도 회차마다 섞습니다 (E02 7.3.1).

「위 모두 정답」처럼 자리를 옮기면 안 되는 보기 139개는 묶어 두었고, 보기가 번호로 서로를 가리키는 36문항은 아예 섞지 않습니다. 섞어도 채점이 그대로인지 219,200회 돌려 확인했습니다.

ASME Sec.V · SNT-TC-1A 와 회사 절차서를 근거로 짓고, 근거 조항을 문항마다 적어 두었습니다. 종목 NDE Level Ⅲ 승인 사항입니다 (E02 6.1.2).

Ⅴ솔직하게

아직 남은 것

  1. 검토 모드를 시행 모드로 바꿔야 합니다. 시행 전 필수 지금은 검토를 위해 은행 문항이 전부 보이게 해 두었습니다. 실제 시험 전에 무작위 출제로 전환합니다.
  2. Level Ⅲ VT는 여유 문항이 없습니다. 규정 65문항에 은행도 65문항이라 회차마다 같은 문항이 나갑니다. 20문항쯤 더 지으면 해결됩니다.
  3. Level Ⅲ 전문시험은 아직 종이입니다. 규정이 그렇게 정하고 있습니다 (E02 5.2.3). 옮기려면 규정부터 고쳐야 합니다.
  4. 실기시험은 다루지 않습니다. 자격 취득에는 실기도 필요합니다 (E01 7.3.1). 필기 결과만으로 합격 처리하지 않도록 화면에 밝혀 적습니다.
  5. 관리자 비밀번호를 제대로 막아야 합니다. 지금은 비밀번호가 화면 쪽에 들어 있어 마음먹으면 들여다볼 수 있습니다. 확인하는 자리를 구글 쪽(Apps Script)으로 옮기면 해결됩니다.
  6. 요원 명단의 시력검사일을 채워야 합니다. 비어 있으면 시력 만료를 계산할 수 없습니다.
