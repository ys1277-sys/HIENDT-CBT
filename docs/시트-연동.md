# 구글 시트 연동 — 응시 기록과 요원 명부

CBT 는 계산과 화면만 맡고 **기록의 원본은 구글 시트에 둔다.**
자격 이력 화면(관리자 → 자격 이력)이 여기서 읽어 온다.

- 응시 기록은 지금도 자동으로 쌓인다. 아래 1번은 **칸을 늘리는 일**이다.
- 요원 명부는 아직 없다. 2번을 만들면 이력 화면이 채워진다.

명부가 없어도 이력 화면은 동작한다. 다만 자격인정 일자를 필기 완료일로
어림하고(「어림」 표시), 시력검사·소속·학력·경력은 비어 있다.

---

## 0. 어디를 고치는가

스프레드시트 → **확장 프로그램 → Apps Script** → `Code.gs` 를 아래 내용으로
바꾸고 → **배포 → 배포 관리 → 새 버전** 으로 다시 배포한다.

> **배포 URL 은 그대로 두어야 한다.** 새 배포를 만들면 주소가 바뀌어
> `src/Admin.jsx` 와 `src/Result.jsx` 의 `SHEET_URL` 도 같이 고쳐야 한다.
> 「배포 관리」에서 **기존 배포를 편집해 새 버전**으로 올리면 주소가 유지된다.

## 1. 응시 기록 시트 — 칸 늘리기

시트 이름: **`결과`** (지금 쓰는 시트)

E02 7.7.7 이 관리자 화면에서 확인할 수 있어야 한다고 정한 값들이다.
**굵은 것이 이번에 새로 추가된 칸**이다.

| 칸 | 뜻 | 비고 |
|---|---|---|
| timestamp | 저장 시각 (ISO) | 정렬용 |
| date | 저장 시각 (읽는 값) | |
| **startedAt** | **응시 시작 시각 (ISO)** | 문항이 화면에 뜬 때 |
| **finishedAt** | **응시 종료 시각 (ISO)** | 제출을 누른 때 |
| **durationSec** | **소요 시간 (초)** | 2시간 초과 확인용 |
| name | 응시자 이름 | 이력의 열쇠 |
| level | Level II / Level III | |
| method | RT · UT · MT · PT · VT · ECT · RFT · TOFD · PAUT · Basic | |
| subject | General / Specific | Level Ⅲ 는 빈칸 |
| total | 출제 문항 수 | |
| correct | 정답 문항 수 | |
| score | 점수 (100점 만점) | |
| result | 합격 / 불합격 | 개별 70% 기준 |
| questions | 출제 문항 (JSON) | 결과지 출력용 |
| answers | 응시자 답 (JSON) | 결과지 출력용 |

머리행에 위 이름을 그대로 적어 두면 아래 스크립트가 이름으로 찾아 넣는다.
칸 차례는 상관없다.

## 2. 요원 명부 시트 — 새로 만들기

시트 이름: **`요원`** (정확히 이 이름)

E03 8.2.1 이 자격인정 기록에 담으라고 한 항목 가운데, 시험을 쳐서 나오지
않는 것들이다. 사람 한 명이 한 줄이다.

| 칸 | 뜻 | 예 | 규정 |
|---|---|---|---|
| name | 성명 — **응시할 때 적는 이름과 똑같이** | 홍길동 | 8.2.1 1) |
| dept | 소속 | 검사1팀 | |
| empNo | 사번 | 2021-014 | |
| eyeExamDate | 시력검사일 | 2026-06-01 | 8.2.1 5) · E01 7.3.2 |
| certifiedAt | 자격인정 일자 | 2026-03-10 | 8.2.1 9) |
| hiredAt | 업무종사 일자 | 2021-03-02 | 8.2.1 9) |
| terminatedAt | 퇴사일 — 보존기간 계산 | | E01 7.6.6 |
| education | 학력 | 기계공학 전문학사 | 8.2.1 3) |
| experience | 경력 | UT 1,200시간 | 8.2.1 3) |
| training | 교육훈련 이수 | UT Level Ⅱ 80시간 (2026-02) | 8.2.1 4) |
| approvedBy | 자격인증 확인 Level Ⅲ | 김OO | 8.2.1 8) |
| employerSign | 고용주 서명 확인 | 2026-03-12 | 8.2.1 11) |

**날짜는 `YYYY-MM-DD` 로 적는다.** 구글 시트가 날짜 형식으로 자동 변환해도
스크립트가 다시 이 꼴로 맞춰 준다.

### 종목마다 인증일이 다를 때

한 사람이 RT 는 2024년에, UT 는 2026년에 땄다면 종목별로 칸을 더 만든다.
칸 이름은 **`certifiedAt:종목`** 이다.

| name | certifiedAt | certifiedAt:RT | certifiedAt:UT |
|---|---|---|---|
| 홍길동 | 2026-03-10 | 2024-05-08 | 2026-03-10 |

종목 칸이 있으면 그것을 쓰고, 없으면 `certifiedAt` 을 쓴다.

### 시력검사가 만료되면

E03 6.1.2 에 따라 시력검사는 검사일로부터 1년 뒤 만료 월의 마지막 날에
만료된다. 이력 화면이 만료·임박을 빨강·주황으로 표시한다.
다시 검사하면 `eyeExamDate` 를 새 날짜로 고친다.

## 3. Apps Script

`Code.gs` 를 통째로 아래로 바꾼다.

```javascript
/*
 * HIENDT-CBT 기록 저장소
 *
 * POST                  응시 결과 한 건을 "결과" 시트에 넣는다
 * GET                   "결과" 시트를 전부 준다
 * GET ?sheet=people     "요원" 시트를 전부 준다 (없으면 빈 목록)
 *
 * 칸은 머리행의 이름으로 찾는다. 칸 차례를 바꿔도 되고,
 * 새 칸을 추가하면 그 이름으로 저장된다.
 */

var RESULT_SHEET = '결과';
var PEOPLE_SHEET = '요원';

function doPost(e) {
  try {
    var body = JSON.parse(e.postData.contents);
    var sheet = sheetOf(RESULT_SHEET, true);
    var head = headerOf(sheet);

    /* 머리행에 없는 칸이 들어오면 뒤에 만들어 준다 */
    var added = false;
    for (var key in body) {
      if (head.indexOf(key) === -1) { head.push(key); added = true; }
    }
    if (added) {
      sheet.getRange(1, 1, 1, head.length).setValues([head]);
    }

    var row = head.map(function (name) {
      var v = body[name];
      if (v === undefined || v === null) return '';
      return (typeof v === 'object') ? JSON.stringify(v) : v;
    });

    sheet.appendRow(row);
    return json({ ok: true });
  }
  catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

function doGet(e) {
  var which = (e && e.parameter && e.parameter.sheet) || '';

  if (which === 'people') {
    return json(readSheet(PEOPLE_SHEET, false));
  }
  return json(readSheet(RESULT_SHEET, true));
}

/* ───────────────────────────────────────────── */

function sheetOf(name, create) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(name);
  if (!sheet && create) sheet = ss.insertSheet(name);
  return sheet;
}

function headerOf(sheet) {
  if (sheet.getLastColumn() === 0) return [];
  return sheet.getRange(1, 1, 1, sheet.getLastColumn())
    .getValues()[0]
    .map(function (v) { return String(v).trim(); });
}

/*
 * 시트를 객체 목록으로 읽는다.
 *
 * questions / answers 는 JSON 문자열로 들어 있으므로 되돌린다.
 * 날짜 칸은 구글이 Date 로 바꿔 두는데, 그대로 주면 시간대가 섞여
 * 만료일이 하루씩 어긋난다. YYYY-MM-DD 로 맞춰 준다.
 */
function readSheet(name, parseJson) {
  var sheet = sheetOf(name, false);
  if (!sheet) return [];

  var rows = sheet.getLastRow();
  var cols = sheet.getLastColumn();
  if (rows < 2 || cols < 1) return [];

  var head = headerOf(sheet);
  var body = sheet.getRange(2, 1, rows - 1, cols).getValues();
  var tz = SpreadsheetApp.getActiveSpreadsheet().getSpreadsheetTimeZone();

  return body.map(function (row) {
    var out = {};

    head.forEach(function (key, i) {
      if (!key) return;
      var v = row[i];

      if (v instanceof Date) {
        /* 시각까지 있는 값은 ISO 로, 날짜뿐이면 YYYY-MM-DD 로 */
        var hasTime = v.getHours() || v.getMinutes() || v.getSeconds();
        out[key] = hasTime
          ? v.toISOString()
          : Utilities.formatDate(v, tz, 'yyyy-MM-dd');
        return;
      }

      if (parseJson && (key === 'questions' || key === 'answers')) {
        try { out[key] = JSON.parse(v); } catch (err) { out[key] = v; }
        return;
      }

      out[key] = v;
    });

    return out;
  }).filter(function (r) {
    /* 빈 줄은 버린다 */
    return String(r.name || '').trim() !== '';
  });
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## 4. 붙였는지 확인하는 법

1. 브라우저에서 배포 URL 뒤에 `?sheet=people` 을 붙여 연다.
   `[]` 가 아니라 명부가 나오면 된 것이다.
2. CBT 관리자 화면 → **자격 이력** 을 연다.
   위쪽 주황색 안내(「요원 명부가 없어…」)가 사라져 있으면 붙은 것이다.
3. 사람 카드에 소속과 시력검사 만료일이 뜨고, 인증일자의 「어림」 표시가
   사라진다.

## 5. 이 문서가 다루지 않는 것

절차서가 요구하지만 **아직 사람이 종이로 관리하는 것**들이다.
CBT 에 넣으려면 따로 정해야 한다.

| 기록 | 서식 | 규정 |
|---|---|---|
| 시험 시행계획서 및 응시자 명단 | E02-01 | E02 7.1 |
| 필기시험 감독 관리사항 | E02-02 | E02 7.4.2 |
| 응시자 유의사항 서명본 | E02-03 | E02 7.4.5 |
| 시험문제 폐기 대장 | E02-04 | E02 7.5.4 |
| 부정행위 처리 기록 | E02-05 | E02 7.6 |
| 문제은행 접근 기록 | E02-06 | E02 6.4.3 |
| 자격증 발급대장 | E03-01 | E03 5.4 |
| 자격증 재발급 신청서 · 대장 | E03-02 · 03 | E03 5.5 |
| 자격종료 · 복권 기록 | E03-05 | E03 7.0 |

**채점결과보고서(E02-07)** 와 **자격 만료 예정자 명단(E03-04)** 은
자격 이력 화면에서 뽑을 수 있다.
